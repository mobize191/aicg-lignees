Notes d'implémentation (pour le prompt couloir 1)

  • Invariant conservé : la fenêtre ne recouvre jamais le terrain ; la barre compacte réduit encore l'emprise (38 % → ~28 % en portrait).
  • Pure UI : HTML/CSS uniquement, aucun changement moteur ni data : digest inchangé attendu.
  • Cibles tactiles ≥ 44 px (WCAG 2.5.5) ; sort indisponible = grisé, jamais masqué (contrainte visible, leçon TCG Pocket).
  • Feedback d'occlusion : la confirmation de ciblage et les dégâts flottent au-dessus de l'unité, jamais sous le pouce ; le mini-log (3 lignes) reste juste au-dessus de la barre.
  • Ordre du tour : les deux camps, ennemis inclus, actif surligné, sélecteur de vitesse persistant en haut-droite (plus de manipulation à chaque tour).
  • À trancher ensuite : vitesses par contexte (§0 n°5, après test terrain de cette maquette).
